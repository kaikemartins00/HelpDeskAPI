# HelpDesk API 🚀

API REST desenvolvida para gerenciamento de chamados técnicos, usuários e técnicos, utilizando Java e Spring Boot.

## 📌 Tecnologias Utilizadas

* Java
* Spring Boot
* Spring Data JPA
* JPA / Hibernate
* PostgreSQL
* Docker
* Maven
* Git & GitHub
* APIs REST
* Postman

---

## 📌 Funcionalidades

* Cadastro de usuários
* Cadastro de técnicos
* Abertura de chamados
* Atualização de chamados
* Integração com banco de dados PostgreSQL
* Persistência de dados com JPA/Hibernate
* Containerização com Docker

---

## 📌 Estrutura do Projeto

O projeto foi desenvolvido utilizando arquitetura em camadas:

* Controller
* Service
* Repository
* DTO
* Entity
* Exception Handler

---

## 📌 Como Executar o Projeto

### Pré-requisitos

* Java 21+
* Maven
* Docker
* PostgreSQL

---

### Clonar o repositório

```bash id="7bjvtl"
git clone https://github.com/kaikemartins00/HelpDeskAPI.git
```

---

### Executar com Maven

```bash id="mjlwmx"
mvn spring-boot:run
```

---

### Executar com Docker

```bash id="xjyl7x"
docker compose up
```
